# Stir Trek Categories — What Got Accepted (2026)

Nine broad categories. For each: size, AI share, themes, and accepted titles. Stir Trek has only one session type.

---

## Artificial Intelligence & Machine Learning — 10 (10 AI)
**Themes:** choosing AI coding workflows; generating quality code with AI; spec-driven development; RAG; vector databases; MCP; multi-agent systems (LangGraph.js); scaling AI across delivery teams; AI in agile planning.
- Choosing an AI Coding Workflow
- How To Code Faster With Spec-Driven Development
- From Copilot to Agent-Native: What We've Learned Scaling AI in Real Software Delivery
- The Vibe Analyst's Guide to AI Coding: From Autocomplete to Agent Orchestration
- Vector Databases and Embeddings Demystified *(also CodeMash 2026)*

## Architecture & Platform Engineering — 9 (1 AI)
**Themes:** microservices (pragmatic, and their dark side); message-based architecture; decision records; OpenTelemetry; Azure messaging reliability; securing Azure AI workloads; architecture patterns; TypeScript.
- Microservices for Pragmatists
- The Dark Side of Microservices
- Boiling The Frog: Implementing a Modern Message Based Architecture Without Anyone Noticing
- When Logs Tell the Whole Story: OpenTelemetry for Beginners *(KCDC 2026: DevOps)*
- Decision Records: Understanding Why Those Decisions Were Made! *(also CodeMash 2026)*

## Application Development — 9 (3 AI)
**Themes:** legacy code and rewrites; sync engines and offline-first; SQL vs NoSQL; .NET Aspire; Java anti-patterns; Git configuration; async JavaScript; side project to production.
- 150K Lines, 0 Unit Tests, No Documentation: How To Work With A Software Landfill
- Completing the Rewrite from Hell: Five Years of Technical Debt and How We Escaped
- Ship It First, Fix It Later: How a Medical Crisis Led to a Global Tool
- Fast, Realtime, and Offline-First Apps with Sync Engines
- Better the Devil you NoSQL - A Battle of Paradigms

## Software Quality & Delivery — 7 (4 AI)
**Themes:** PR review practice; quality in the era of AI-written code; Playwright UI tests; satirical DevOps; maintaining code without reading every line; product thinking in modernization.
- LGTM is not a Strategy
- Ensuring Software Quality in the world of AI Developers
- The DevOops Handbook: A satirical guide to slow software delivery
- Maintenance by Smell: When Reading Every Line Becomes Obsolete
- Automating User Interface Tests with Playwright

## Professional Growth & Leadership — 7 (2 AI)
**Themes:** tech-debt prioritization; leading through change; AI productivity pressure; starting a new role; side businesses; metrics-driven coaching; managing failure.

**Pattern:** Stir Trek's categories are organized by **what the talk does for you** (build apps, run platforms, ship quality, grow), not by technology stack. Platform talks (TypeScript, OpenTelemetry) were placed in *Architecture & Platform Engineering*.
